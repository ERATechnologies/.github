# Contributing

Thank you for your interest in supporting ERA Technologies™.

This repository is intended for corporate GitHub profile, community-health, and shared engineering standards. It is not a product or application repository.

## Scope

Contributions should stay focused on organization-level documentation, standards, and governance guidance. Avoid introducing unrelated product, project, or operational claims.

## Expectations

- Keep documentation accurate, maintainable, and respectful.
- Prefer clear, factual language over promotional claims.
- Do not publish sensitive information, private contact details, or confidential internal company policy.
- Ensure any proposed wording is consistent with the company identity and approved public information.

## Review process

Changes should be reviewed by an authorized maintainer before merge. The repository is intended to support secure, professional public-facing standards rather than project delivery.
